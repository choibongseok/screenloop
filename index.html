실행 범위 기기 네 대의 동기화 코드와 서버의 판정 규칙은 브라우저 안에서 도는 실제 TypeScript 코드입니다. 서버는 이 페이지 안의 가짜 서버입니다. 정산 계산은 Kotlin 서버 코드라 브라우저에서 돌리지 않고, 실제로 실행한 결과 파일을 읽어 옵니다.

매장 화면 동기화 모의 테스트

매장 화면 하나를 운영 웹, 휴대폰 리모컨, TV, PC 네 곳에서 같은 상태로 보게 하는 동기화 코드를 TypeScript 로 만들었고, 화면이 남긴 재생 기록으로 월 요금을 계산하는 서버를 Kotlin·Spring Boot 로 만들었습니다. 아래에서 기기를 일부러 고장 내 보고, 다시 같은 상태로 맞춰지는지와 재생 기록이 몇 건 모였는지 확인할 수 있습니다.

매장·콘텐츠·요금은 모두 예시 데이터입니다. 화면의 장면은 직접 만든 SVG 입니다.

      명세와 코드가 어긋나면 막힙니다 일부러 깨뜨려 본 결과

      OpenAPI 명세에서 TypeScript 타입과 이벤트 스키마를 만들고, 서버 응답은 그 명세로 검사합니다. 명세만 바꾸거나 코드만 바꾸면 make verify 가 실패합니다. 실제로 그렇게 바꿔서 돌린 출력입니다.

      용어 풀이
      스냅샷
      화면 상태 전체를 한 번에 받는 것. 이벤트가 중간에 빠졌거나 끊겼다 다시 붙을 때 이걸로 따라잡습니다.
      버전
      서버가 상태를 바꿀 때마다 1씩 올려 붙이는 번호. 기기는 번호가 이어질 때만 이벤트를 적용합니다.
      멱등
      같은 요청을 몇 번 보내도 결과가 한 번 보낸 것과 같은 성질. 재생 기록은 (기기, 일련번호)로 이를 지킵니다.
      시계 차이
      기기 시계와 서버 시계가 다른 정도. 기기는 서버가 알려 준 시각으로 차이를 재서 재생 위치를 서버 시각 기준으로 계산합니다.
      마감과 조정
      월을 마감하면 그 정산서는 고치지 않습니다. 마감 뒤에 늦게 도착한 기록은 다음 정산서에 조정 항목으로 들어갑니다.
      예시 데이터만 씁니다. 이 페이지는 외부 서버에 요청을 보내지 않습니다. 쿠키는 설명을 이미 봤는지 기억하는 sl_tour 하나만 쓰고, 개인 정보는 담지 않습니다.
